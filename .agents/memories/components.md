# Componentes Reutilizables

## Navegación
- `AppBar` → Top bar con título y acciones
- `TopBar` → Barra superior del reader
- `BottomNavs` → Bottom tab navigation (4 tabs con Ionicons)

## Libros y Lectura
- `BookCard` → Card de libro (soporta locked state)
- `BookSlider` → Slider horizontal con "Ver todos"
- `DualPanelReader` → Lectura lado a lado (dos idiomas)
- `InterleavedReader` → Oraciones intercaladas
- `SingleReader` → Un solo idioma
- `ReadingBar` → Barra de progreso de lectura
- `PageContent` → Renderizado de contenido de página

## Recorridos
- `RecorridoCard` → Card de learning path
- `RecorridoSlider` → Slider horizontal de recorridos

## Generales
- `SearchInput` → Input de búsqueda
- `FilterModal` → Bottom sheet de filtros por categoría
- `ChipSelector` → Selector de chips/chips
- `ProfileCard` → Card de perfil
- `VideoPlayer` → Modal WebView para YouTube
- `HomeLoading` → Skeleton loading de home
- `AppLoading` → Pantalla de carga inicial
