# Pantallas

## Home (`/(app)/home`)
Dashboard: search + filters + sliders (descubrir, leyendo, favoritos, categorías, tags, recorridos)

## BookDetail (`/book/[id]`)
3 tabs: Detalle (info, stats, vocabulario con TTS), Reseñas (rating, comentarios), Similares (recomendaciones por scoring)

## Reader (`/reader/[bookId]`)
Interfaz de lectura completa: 3 modos, temas, TTS, guardar vocabulario, finalizar libro con XP + trofeos

## Videos (`/(app)/videos`)
YouTube agrupado por categoría, filtro por idioma, modal WebView player

## Study (`/(app)/study`)
Vocabulario: modo flashcard (flip + mastery) + escritura, filtro por dificultad

## Profile (`/(app)/profile`)
Stats: avatar, XP, nivel, logros, sesiones recientes, historial XP, editar nombre

## RecorridoDetail (`/recorrido/[id]`)
Progreso, lista de libros con lock/unlock, iniciar path

## LanguageSetup (`/language-setup`)
Onboarding: seleccionar idioma nativo

## Auth (`/(auth)`)
Login/Register con email + password
